# Learning mode

Develop the material in the learner's own words. Clarify the concept, connect it to prior knowledge, add a worked distinction or example when useful, and identify a plausible use. Follow the local authority hierarchy. In an academic vault, course materials outrank general knowledge when the contract says so.

Write a note that can support later retrieval without pretending retrieval has happened. A learning note is complete when the user has usable material for a test, not when the note merely looks polished. Keep the conceptual state "learned" separate for `test-understanding` to establish through evidence.
