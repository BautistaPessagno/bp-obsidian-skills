# Test understanding

Measure what the user can produce without support, then repair only the observed gap. A complete session ends with successful transfer to a new case or an explicit recorded blocker and next step.

## Prepare

Confirm the active vault boundary. Read its agent guide, BP Vault contracts, the target note, and the local sources needed to judge the answer. If the contracts are missing, recommend `setup-bp-vault` before persisting evidence. Use the note's language.

Choose a narrow target and state what ability the test will check. Follow the local source hierarchy. Course notes, notation, and scope take priority when the method contract says they do.

## Retrieval loop

1. Ask one prompt that requires the user to recall, explain, derive, or perform without displaying the answer. Wait for the response.
2. Compare the response with the authoritative material. Name the smallest concrete gap: missing fact, faulty distinction, broken step, weak connection, or unsupported confidence.
3. Teach only enough to repair that gap. Make source conflicts visible and keep fact, interpretation, and experience distinct.
4. Ask a different case that requires transfer, not repetition of the same wording. Wait for the response.
5. If transfer fails, repeat from the newly observed gap. Stop when the user solves a new case or when a prerequisite blocks progress.

Do not count note volume, elapsed study time, recognition, or a polished explanation shown moments earlier as proof of understanding.

## Evidence

Persist only errors, unresolved gaps, new connections, and the next review when the local contracts define a destination. Do not save a transcript or routine correct answers. Preview any substantial note change and get approval unless the structure contract explicitly classifies the evidence update as mechanical.

Map the conceptual state "learned" only after the user has demonstrated both retrieval and transfer, and only through a property mapping already defined by the local method contract. Otherwise report the evidence in plain language without inventing a status.
